# Learn SecByte Thor, Shellshock, GTFOBins, FTP & Gobuster CTF Labs

These labs provide a structured way to practice reconnaissance, service discovery, web enumeration, exploitation concepts, initial access, privilege escalation, and post-exploitation tasks in controlled CTF environments.

The supplied URLs indicate technologies and techniques including **Shellshock, CGI, Gobuster, GTFOBins, FTP, service binaries, banner enumeration, and Thor-based labs**. Difficulty ratings and CVE identifiers are not assumed unless explicitly indicated by the supplied URLs.

## Learning Path

A useful progression through this collection is:

1. **Begin with Thor Enumeration Trail** to establish a systematic reconnaissance process.
2. **Practice Gobuster enumeration** to identify web content and potential attack surfaces.
3. **Explore FTP reconnaissance** with Thunder FTP Trail.
4. **Study HTTP and CGI reconnaissance** before moving into Shellshock-focused exercises.
5. **Work through the Shellshock labs** to understand the relationship between HTTP, CGI, and vulnerable command processing.
6. **Practice service binary and GTFOBins concepts** in controlled privilege-escalation scenarios.
7. **Complete Thor's Root Access Run** to combine enumeration and escalation concepts.
8. **Finish with flag-hunting and review-oriented exercises** to reinforce the full CTF workflow.

## How to Use the Labs

1. Open a lab from the direct-link index.
2. Read the target and authorization instructions before testing.
3. Start with reconnaissance rather than immediately attempting exploitation.
4. Enumerate HTTP, FTP, CGI, directories, services, and banners where relevant.
5. Record findings and use them to guide the next step.
6. Apply exploitation techniques only to the authorized lab environment.
7. If a foothold is obtained, inspect available privilege boundaries carefully.
8. Document commands, observations, vulnerabilities, and lessons learned.
9. Reset and repeat the lab to improve your methodology.
